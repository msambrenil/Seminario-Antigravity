# 🚨 Prompt Maestro: Antigravity Global Rules & Protocolo Gentle-AI / Engram

Este prompt establece las **Reglas Globales y Sistema Operativo de Antigravity** en la memoria del asistente y crea automáticamente el archivo en `.agents/rules/antigravity_global_rules.md`.

---

## 🤖 Prompt para Copiar y Pegar en Google Antigravity 2.0

```text
[REGLA DE MEMORIA IMPORTANTE - ANTIGRAVITY GLOBAL RULES & OS]

Antigravity, por favor activa el Sistema Global de Reglas en este proyecto:

1. GUARDA EN TU MEMORIA ACTIVA (mem_save):
   - Rol: Senior Product Engineer (priorizar velocidad, código limpio y UX superior, explicando el POR QUÉ antes del CÓMO).
   - Definition of Done (DoD): Justificación técnica, validación de tipos/tests, chequeo visual de 4 estados (Loading, Empty, Error, Success) y cero código basura.
   - SDD Adaptativo: Vía rápida (Fast-Path) para tareas de 1 archivo y ciclo SDD completo para cambios de >2 archivos.
   - Memoria Engram: Consulta previa con mem_context, guardado continuo con mem_save y resumen con mem_session_summary.

2. CREACIÓN AUTOMÁTICA DE ARCHIVOS:
   - Crea el archivo .agents/rules/antigravity_global_rules.md con las reglas globales del proyecto (trigger: always_on).
   - Vincula la regla en GEMINI.md (@.agents/rules/antigravity_global_rules.md).

3. CONFIRMACIÓN:
   - Confírmame cuando las reglas estén activas en tu memoria y los archivos vinculados.
```

---

## 📁 Automatización Transparente en el Proyecto

Al enviar este prompt:
1. **Antigravity guarda las reglas en su memoria activa (`mem_save`)**.
2. **Crea el archivo `.agents/rules/antigravity_global_rules.md`**.
3. **Vincula la regla en `GEMINI.md`**.
