# 🔄 Flujo de Trabajo y Definition of Done (DoD)

## 🚀 Proceso de Maquetado y Desarrollo Agentico

1. **Investigación Previal (`sdd-explore`)**:
   - Inspeccionar los componentes existentes y validar clases de TailwindCSS antes de maquetar.
2. **Especificación & Tareas (`sdd-propose` / `sdd-tasks`)**:
   - Redactar los requerimientos de la nueva sección o componente en el checklist de tareas.
3. **Aplicación (`sdd-apply`)**:
   - Escribir el código HTML/CSS/JS siguiendo las convenciones de `convenciones.md`.
4. **Verificación (`sdd-verify`)**:
   - Comprobar que el componente sea responsive, respete la paleta de colores y funcione en Dark/Light mode.
5. **Persistencia en Memoria Engram**:
   - Ejecutar `mem_save` tras cada decisión o solución de error.

---

## ✅ Checklist de Definition of Done (DoD)
- [ ] HTML semántico validado.
- [ ] Diseño 100% Responsive (Mobile, Tablet, Desktop).
- [ ] Dark / Light mode funcional con persistencia en `localStorage`.
- [ ] Cero errores en la consola de JavaScript.
- [ ] Memoria Engram registrada y resumen de sesión completado.
