# 📖 Glosario de Términos del Proyecto (CultivaRío 2026)

## 🎭 Términos de la Página Web
- **CultivaRío 2026**: Sitio web y nombre del Festival Cultural de Río Cuarto, Córdoba.
- **Parque del Andino**: Lugar donde se realizan los eventos y espectáculos principales del festival.
- **Entrada Gratuita QR**: Código de confirmación que obtiene la persona al enviar el formulario de reserva.
- **Atracción / Evento**: Cada una de las actividades culturales (música, muestras de arte, peñas o talleres).

## 💻 Términos de Maquetado y Desarrollo
- **Página Web SPA (Single Page Application)**: Sitio web interactivo que cambia de sección (Landing, Catálogo, Dashboard) al hacer clic en el menú sin tener que recargar la página en el navegador.
- **Datos de Prueba (Mock Data)**: Lista de información ficticia o de ejemplo en JavaScript (`MOCK_EVENTS`) usada para rellenar las tarjetas del catálogo.
- **LocalStorage**: Memoria del navegador que guarda las entradas reservadas y el tema elegido (Modo Claro u Oscuro) para que no se borren al refrescar la pantalla.
- **Master Context**: Los 6 archivos en la carpeta `docs/contexto/` que contienen las reglas y la información del proyecto para Antigravity 2.0.
- **Gentle-AI (SDD)**: Método de trabajo donde el agente investiga, propone tareas y verifica la web antes de entregarla.
- **Engram**: Memoria persistente donde Antigravity guarda las decisiones tomadas durante el desarrollo.
